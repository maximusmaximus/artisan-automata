# Code of Use

Artisan-Automata is a **generation pipeline**, not a license to copy other people's work.

## Required

- Produce an original interactive mechanic each run. Inspired-by is allowed; clones are not.
- Credit public references in `ledger/runs/` (post URLs, artist handles, library names).
- Discover trends with Grok X tools (`x_keyword_search`, `x_semantic_search`, `x_thread_fetch`). Do not scrape X.com, do not circumvent rate limits, do not collect emails or private data.
- Request only `drive.file` for Google Drive. Never request full-drive scopes.
- Never commit secrets, OAuth client secrets, refresh tokens, or user Drive contents.
- Never grant admin to "the first user who logs in." Use `ADMIN_USER_IDS` / `ADMIN_EMAILS`.

## Forbidden in generated apps

- Non-consensual imagery, CSAM, or sexual content involving minors (including fictional).
- Weapons, explosives, poisons, or attack-method how-tos dressed up as generative art.
- Credential harvesting, clickjacking, or hidden network exfiltration.
- Shipping a copy of a trademarked product UI as the "novel" app.

## Attribution

Generated apps should include a discreet credit: built with the Artisan-Automata pipeline, plus any third-party library licenses (Three.js, Tone.js, etc.).
