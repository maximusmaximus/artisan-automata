# Aggregating generated apps

Every app produced by this pipeline must stamp a back-reference to
https://github.com/maximusmaximus/artisan-automata.

That stamp is how the fleet is discovered. Do not omit it.

## What each generated app must contain

1. Root file `artisan-automata.json` matching [`schemas/provenance.schema.json`](../schemas/provenance.schema.json).
   Required constants:
   - `"generator": "artisan-automata"`
   - `"pipeline": "https://github.com/maximusmaximus/artisan-automata"`
2. `package.json` fields:
   - `keywords` includes `artisan-automata`
   - `artisanAutomata.pipeline` is the same pipeline URL
   - `artisanAutomata.slug` is the app slug
3. README line: `Generated by [Artisan-Automata](https://github.com/maximusmaximus/artisan-automata).`
4. Visible credit: render `templates/ProvenanceMark.tsx` from `app/layout.tsx`.
5. GitHub topic `artisan-automata` on the generated repository when the API allows it.

Never put API keys, pairing tokens, or emails in the provenance file.

## How to list the fleet

GitHub code search:

```text
"generator": "artisan-automata" filename:artisan-automata.json
```

```text
"https://github.com/maximusmaximus/artisan-automata" filename:artisan-automata.json
```

```text
artisan-automata in:readme
```

GitHub topic search:

```text
topic:artisan-automata
```

Owner-scoped:

```text
user:maximusmaximus filename:artisan-automata.json
```

Venice Key Manager project name for inference keys remains `ArtisanAutomata` so spend can be aggregated separately from the GitHub fleet.
